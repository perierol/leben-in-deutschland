# Report template

Write the report in this structure. Keep every section. If a section is empty, write "None" rather than leaving it out. Replace `<…>` placeholders and remove these instructions.

```markdown
# Android audit · <scope description> · <YYYY-MM-DD>

> Local, untracked report generated by `/android-audit`. Not staged or committed.
> All findings come from read-only reviewers. No builds, tests or device checks were run by this audit.

| Date | <YYYY-MM-DD HH:MM TZ> |
| Branch / commit | <branch> @ <short sha> |
| Scope | <type>: <description>. Base <sha> → head <sha> (diff scopes) |
| Files in scope | <count>; diff at `<scratchpad path>` (not kept) |
| Working tree | <clean, or the list of uncommitted and untracked paths; note which were not reviewed> |
| Arguments | `<raw $ARGUMENTS>` |

| Reviewer | Run? | Review status | Triggered by | Focus areas |
|---|---|---|---|---|

| android-testing-reviewer | … | … | … | — |
| android-security-reviewer | … | … | … | <focus areas> |
```
